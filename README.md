# BU Bioinformatics Shared Infrastructure Setup

This is a repository designed to give you universal instructions on how to
perform a series of shared tasks to prepare you to work on the Shared Computing
Cluster (SCC), interact with git and Github, work with agentic coding harnesses,
and manage your computational environments across bioinformatics program
classes.

Please go through the steps in order (skip steps if you've already done them).

# Part 1 - Setting up infrastructure

## Setup steps

1. [General Policies on AI and LLM Usage](docs/01-general-policies/README.md)
2. [Fill out the student intake form on the internal website](docs/02-student-intake-form/README.md)
3. [Accept the Claude Invitation sent to you](docs/03-claude-invitation/README.md)
4. [Claude Desktop App](docs/04-claude-desktop-app/README.md)
