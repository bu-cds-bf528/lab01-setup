# Fill out the student intake form on the internal website

If you haven't already done this, please do so now. If you have, please skip to
the next section.

We need to be able to associate your BU username with your Github username as
several of our classes distribute their work over the platform. As mentioned in
our earlier communications, if you don't have a Github account or prefer to
create a separate one specifically for your professional work, please do so at:
https://github.com/signup

Once done, please navigate to our internal website (you will need to sign-in)
and fill out this form:
https://sites.bu.edu/bioinfo-ms/forms-and-submission-links/incoming-student-intake-form/
