# Git and Github Setup

We will be making extensive use of git and Github as a way of tracking changes
in your code. With the advent of agentic coding, proper git practices are
becoming essential as a way of validating and reviewing any LLM-generated code
prior to merging it into a working codebase.

We are going to create and set up an SSH key on the SCC that will allow you to
authenticate and perform basic git operations on the SCC.

Please follow the instructions
[here](https://www.bu.edu/tech/support/research/system-usage/connect-scc/access-and-security/using-scc-with-github-2fa/#AUTH)
to set up an SSH key.

You will need to remember to make sure you clone the repo using the appropriate
SSH link, **not** the https protocol.

- [ ] Successfully set up an SSH key
- [ ] Accept and clone the provided classroom50 link
- [ ] Practice a small git cycle of add, commit, push and pull
