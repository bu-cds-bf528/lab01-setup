# Claude Code CLI SCC Setup

Open a terminal in your VS Code session, and follow the instructions at this
link to install the Claude Code CLI app:
https://code.claude.com/docs/en/setup#install-a-specific-version

Install the latest version using the command for macOS, Linux, WSL
```
curl -fsSL https://claude.ai/install.sh | bash
```

Follow any instructions that are spawned by the command above, including the
command to add Claude Code to your path. Please run Claude Code using the
following command:

```
claude
```

Use the on-screen instructions to authenticate with your Claude license through
your BU email.
